# Verilog Projects

Welcome to my digital logic design workspace! I am an electronics engineering student, and this repository serves as a portfolio of my Verilog projects. This repo scales progressively from foundational combinational logic up to complex sequential circuits.

## Tools Used
* Language: Verilog 
* Simulation & Verification: Altera ModelSim Intel FPGA Starter Edition 10.5b (Quartus Prime 18.1)
* RTL Visualization: [DigitalJS](https://digitaljs.tilk.eu/)

## Project Structure
Each project folder is self-contained and includes:
* Verilog Code: Source files (`.v`) of top-level and sub-modules and testbenches in a separate Code folder.
* README: Contains the logic and explaination of the design. Only present for designs which I believe are more complex and harder to understand
* RTL Schematics
* Simulation Waveforms

## How to Run
1. Clone the repository: `git clone https://github.com/vedantkarmarkar20-sys/verilog-projects.git`
2. Open ModelSim and compile the `.v` files located in the `Code` folder.
3. Run the testbench file to view the simulation waveforms.
